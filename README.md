# Campus-Hub-Africa
CampusHub Africa est le réseau que j'aurais aimé avoir pour mes études. Une plateforme pour les étudiants d'Afrique francophone qui centralise bourses, stages et logements. On peut chatter en direct, poser des questions et trouver des étudiants de sa filière. Projet développé avec Next.js, Node.js et PostgreSQL.
